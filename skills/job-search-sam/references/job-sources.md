These links were supplied by the plugin creator. They are starting points, not a guarantee of current availability, free access, search coverage, or suitability for every user. For each run, attempt the 46 primary sources below unless the individual user changes their source preferences. Only report a source as searched if actually searched; record inaccessible, irrelevant, unsearched, sign-in-gated and failed sources separately. Never report a web search result mentioning a site as an exhaustive search of that site. Check relevant employer postings and deduplicate results. Honor applicable site requirements and access controls. Do not promise exhaustive coverage when tooling or access makes it impossible.

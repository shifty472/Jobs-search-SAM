# Job Search SAM prototype status

This is an early prototype. The tracker records job information, search preferences and optional application answers in the current browser on the current device. It provides an MCP workflow-description tool.

It does not submit applications, verify submission counts, generate application documents, upload resumes, synchronize across devices, or connect email or GitHub. Browser storage is readable by people with access to that browser profile; do not enter sensitive information on a shared device.

Planned work includes secure user accounts and storage, resume-based document generation, per-application approval for the first 25 verified submissions, opt-in automation, optional integrations, and extensive testing. The prototype is not production-ready. Deployment configuration and credentials are not included in this public repository.

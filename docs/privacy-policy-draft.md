# Job Search SAM Privacy Policy — Draft for review

This is a working draft based on the current instruction-only plugin. It is not a published or finalized privacy policy. The provider's legal identity, actual data flows, retention rules and user rights must be verified before release.

## Service and contact

Job Search SAM is a free guided job-search workflow. The provider is Jacob Lewandowski, acting as an individual. Users can contact the provider through https://github.com/shifty472/Jobs-search-SAM/issues. GitHub issues are public; do not include resumes, disability information, contact details, credentials, or other sensitive information in a public issue.

## Information users may provide

Depending on what the user chooses to do, information may include a resume, education and employment history, preferred job titles, locations, compensation preferences, writing samples, application answers, or links to job-search sources. Sensitive or special-category data is requested only when strictly necessary for a specific user-requested task, after a clear explanation and legally adequate consent. Optional details may be skipped. Users should remove government identifiers, passwords, authentication codes, payment-card data and protected health information before sharing materials.

## Why information is used

The workflow uses information provided by the user to understand job preferences, assess opportunities, help prepare truthful application materials, and carry out actions the user requests and authorizes. Writing samples may be used to adapt writing style at the user's request. SAM should not infer protected characteristics or include sample content as a fact about a user without verification.

## Where information goes

The plugin runs through the host platform. Information submitted through the host is processed by that platform. When users separately authorize connected tools, websites, email providers, or employers, those parties may receive information necessary to perform the chosen action and apply their own policies. Users should review destinations and permissions before sharing. At the time of this draft, the creator has stated they do not personally collect users' job-search information through a separate developer-operated database; confirm the actual implementation before publication.

## Retention and deletion

The developer does not currently operate a separate application database for this plugin. The host platform and any storage or connected services the user chooses may retain information according to their own settings and policies. Users should use those services' controls to manage or delete their information. Support requests posted as GitHub issues remain on GitHub until the provider removes them or the person who posted them requests removal, subject to applicable law and GitHub's systems and policies. GitHub may retain copies or records under its own policies. Contact the provider through the support channel to request removal, and do not include sensitive information in a public request.

## Security and choices

Users may decline optional information and should review what will be shared before any action. No system can guarantee absolute security. The provider must document and implement any security and incident-response measures that apply to the actual service and notify users when required by law. Contact the provider about concerns without posting sensitive information publicly.

## Changes

The provider must establish how material policy changes will be communicated and update this policy as actual data practices change. This draft does not itself establish a notification promise, governing law, or any jurisdiction-specific rights procedure.
